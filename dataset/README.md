# 📂 Dataset

This project uses the **Brain Tumor MRI Dataset** available on Kaggle.

### Dataset Link

https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

### Classes

- Glioma
- Meningioma
- Pituitary
- No Tumor
